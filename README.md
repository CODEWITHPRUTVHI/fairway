# FAIRWAY — Fair Fares. Smarter Routes.

An intelligent shared mobility and algorithmic ride-pooling platform. FAIRWAY matches passengers travelling in compatible directions, selects optimal meeting points, enforces a **hard 15% detour limit** per passenger, and calculates mathematically fair fares and driver earnings using **Shapley Value cost allocation**.

## Key Features
- **Customer Mobile App**: Hanoi city map, quick destinations, vehicle tier selection, women-only matching, Shapley cost breakdown, 4-digit PIN verification, live driver tracking, and SOS safety center.
- **Driver Mobile App**: Driver availability, assignment acceptance, meeting point navigation, PIN validation, and earnings ledger (12% platform commission).
- **Operations & Admin Console**: Live batching inspector, strict 15% detour auditor, interactive Shapley sandbox, and 100-request reproducible benchmark runner.
- **Dual Display Mode**: Realistic iPhone frame touch simulator and full responsive desktop view.
- **Built-in Verification Suite**: Verifies all 9 core business rules in real time.

## Quick Start
```bash
npm install
npm run dev
```
Open `http://localhost:3000` in your browser.
