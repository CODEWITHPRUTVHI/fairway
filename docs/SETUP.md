# docs/SETUP.md — Local Setup & Cross-Device Instructions

## Quick Start
1. Clone repository:
   ```bash
   git clone <repo_url>
   cd fairway
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run development server:
   ```bash
   npm run dev
   ```
   Server will listen on `http://localhost:3000`.

4. Typecheck & Build:
   ```bash
   npm run lint
   npm run build
   ```
